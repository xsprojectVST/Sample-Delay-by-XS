# Sample Delay by XS

**Sample Delay by XS** is a free audio utility plugin for precise left/right channel delay, phase control and pitch adjustment.

Designed for mixing, stereo alignment, phase correction, sound design and creative stereo processing.



## Watch Demo Video (Youtube):
[![Watch Demo Video](https://img.youtube.com/vi/8i7-tHXmDM0/maxresdefault.jpg)](https://youtu.be/8i7-tHXmDM0)

## Features

* Independent **Left / Right sample delay**
* Delay range up to **±5000 samples**
* Delay displayed in **samples and milliseconds**
* Fine adjustment with the mouse wheel
* Independent **Pitch** control for Left and Right channels
* Semitone and cents adjustment
* Independent **Phase Invert** for each channel
* Independent **Bypass** for each channel
* Global bypass
* **LINK** mode for controlling both channels together
* **MONO OUT** mode
* Smooth parameter transitions with **10 ms crossfade** to reduce clicks and artifacts
* Resizable user interface
* Multiple interface color themes
* Double-click controls to quickly reset values
* Lightweight and designed for real-time audio processing

## Installation

### Windows — VST3

Copy:

`Sample Delay by XS.vst3`

to:

`C:\Program Files\Common Files\VST3\`

Then restart your DAW or rescan your plugins.

### Windows — CLAP

Copy:

`Sample Delay by XS.clap`

to:

`C:\Program Files\Common Files\CLAP\`

Then restart your DAW or rescan your plugins.

### macOS — VST3

Copy the plugin to:

`/Library/Audio/Plug-Ins/VST3/`

### macOS — Audio Unit

Copy the plugin to:

`/Library/Audio/Plug-Ins/Components/`

### macOS — CLAP

Copy the plugin to:

`/Library/Audio/Plug-Ins/CLAP/`

Restart your DAW after installation.

## Controls

### SAMPLE DELAY

Adjusts the delay of the Left or Right audio channel in individual samples.

This can be useful for:

* Phase alignment
* Microphone alignment
* Stereo image adjustment
* Haas-style stereo effects
* Timing correction
* Creative stereo processing

### PITCH

Adjusts the pitch of the Left and Right channels independently.

Pitch controls are independent from the sample delay controls.

### LINK

Links Left and Right controls for simultaneous adjustment.

### MONO OUT

Combines the processed signal to mono.

### PHASE

Inverts the polarity of the selected channel.

### BYPASS

Each channel can be bypassed independently.

A global bypass control is also available.
